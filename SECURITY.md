# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older
commits and locally modified copies are not supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing
`support@apollo.io` with the subject `[claude-statusline security]`. Do not open
a public issue or include live OAuth tokens, credentials, or other secrets in
the report.

Include the affected version or commit, the impact, reproduction steps, and
any suggested mitigation. Apollo will acknowledge the report, investigate it,
and coordinate disclosure after a fix is available.
